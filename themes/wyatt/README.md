# Wyatt

MMWX 主控自定义主题。奶油底、浅蓝按钮、薄荷绿强调色、深色圆角描边与偏移硬阴影。

版本：`v2026.11.02-04`，适配 MMWX `v0.6.2-beta.4`。

## 文件

- [controller.css](controller.css)：完整主控样式，可独立粘贴使用。
- 本主题暂不提供 TG Bot Mini App 样式。

## 安装与更新

先备份现有 CSS，再打开 `controller.css` 的 **Raw** 内容，完整替换「系统设置 → 外观 → 自定义 CSS」，保存并刷新。也可以使用编辑框的「从链接更新」功能加载该文件的 Raw 链接，然后手动保存。

不要叠加其他主题。自定义 CSS 功能是否可用，以所用 MMWX 版本和许可证为准。

## 注意事项

本文件使用 CSS 嵌套、`:has()` 和 `color-mix()`，请使用现代浏览器。字体来自 Google Fonts，网络不可用时自动回退到系统字体。

文件大小为 62,669 个 UTF-8 字节（去掉末尾换行为 62,668 字节），低于网站的 65,536 字节上限。继续追加代码前仍应检查容量，避免保存失败或内容不完整。

本版按新版虚拟列表结构重写节点布局，移除旧列数规则，统一按钮入口并修复手机转发编辑器、个人菜单与系统设置页的显示问题；保留原主题风格及手机、深色和交互状态样式。

节点底部批量操作栏使用浅蓝按钮、薄荷绿数量徽章与主题外框。桌面六个按钮横排，手机三列两行，无需横向滚动；删除保留红色提示。

节点「更多操作」面板采用两列浅蓝操作块，图标与文字横排、垂直居中；标题地址可换行，删除保留红色。手机端按内容高度显示，四周保留边距，短屏可滚动。

样式仅调整显示，不改变业务逻辑。排序功能仍由 MMWX 提供：先开启「排序模式」，再使用节点左侧的小点拖动。排序入口以当前程序显示为准。套餐权限和功能开关也由程序决定，CSS 不会解锁功能。

由于适配依赖 MMWX 组件结构，程序升级后可能需要调整选择器。完整说明见 [仓库 README](../../README.md)，版本变化见 [更新记录](../../CHANGELOG.md)。
